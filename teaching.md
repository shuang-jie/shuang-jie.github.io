## Teaching

<p class="lede">I teach applied, computing-first statistics — students spend class time writing code against real data rather than watching derivations.</p>

<div class="course">
  <div class="course-head">
    <span class="course-code">SDS 322E</span>
    <span class="course-term">Spring 2026 &middot; UT Austin</span>
  </div>
  <h3>Elements of Data Science</h3>
  <p>Data science tools and workflow: data wrangling, exploratory analysis and visualization, Markdown and reproducible reporting, simulation-based inference, and classification. R is emphasized; Python is introduced.</p>

    <div class="unit">
      <span class="unit-no">Unit 1</span>
      <h4>Analytic Thinking and Visualization</h4>
      <p>Tidy data, summarizing in one and two dimensions, basic visualization, and R Markdown notebooks.</p>
    </div>
    <div class="unit">
      <span class="unit-no">Unit 2</span>
      <h4>Data Wrangling</h4>
      <p>ggplot2, dplyr, and tidyr: reshaping, joining and merging, missing data, regular expressions and text.</p>
    </div>
    <div class="unit">
      <span class="unit-no">Unit 3</span>
      <h4>Modeling and Analysis</h4>
      <p>Clustering and PCA, linear and logistic regression, tree-based methods, prediction metrics, cross-validation.</p>
    </div>
    <div class="unit">
      <span class="unit-no">Unit 4</span>
      <h4>Expanding Horizons</h4>
      <p>Causal inference, propensity scores, and building dashboards.</p>
    </div>
  </div>
</div>

**By the end of the course, students can** write R code and build analyses in R Markdown; use Tidyverse tools to wrangle, clean, and visualize data; and fit supervised and unsupervised models to quantify relationships in high-dimensional data.
